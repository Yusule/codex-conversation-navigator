# Codex 对话目录

这是一个本地 Windows 悬浮工具。点击屏幕上的液态玻璃悬浮球，会以左右聊天气泡展示当前 Codex 任务中的用户消息与 ChatGPT 回复；点击任意一行可直接滚动到对应消息。

## 使用

1. 保持 Codex 桌面版已打开，并进入一个任务。
2. 双击 `start.cmd`，或通过 Codex 插件里的 Conversation Navigator 技能启动。
3. 点击紫蓝色悬浮球打开目录；展开后图标会切换成青蓝金色，收起闲置 8 秒后会淡化到 62%，鼠标移入或键盘聚焦会恢复清晰。
4. 用户消息显示在右侧，大模型回复显示在左侧；点击顶部“全部 ⇄”可循环切换“全部 / 模型 / 用户”。
5. 点击目录行完成定位；面板会在悬浮球旁边自动选择空间充足的一侧展开。
6. 拖动悬浮球，或拖动目录标题栏左侧的标题与双线把手，可以移动整个悬浮组合；方向键可微调位置，右键悬浮球可退出。

如果 Codex 主窗口已经最小化，打开目录时会先恢复它，以便读取当前任务的消息。

## 隐私与资源

- 工具不访问网络。
- 工具只通过 Windows UI Automation 读取当前 Codex 窗口中已经显示的可访问性文本。
- 打开面板时会在内存中采样面板后方的本机屏幕区域，用来生成毛玻璃背景；采样图像不会保存到文件，也不会上传。
- 当 Codex 界面被挂起而暂时没有可访问性文本时，工具会先调用官方宠物的“打开通知”；没有活动通知时，才通过 Codex 本地 app-server 唤醒最近更新的任务。
- 不修改 Codex 安装目录，也不向 Codex 进程注入代码。
- 只在打开或刷新目录、点击定位时扫描界面，空闲时不会持续轮询。
- 程序只允许一个实例；再次启动会直接唤醒并切换目录面板。

## 当前边界

- 仅支持 Windows Codex 桌面版。
- 依赖 Codex 当前提供的“你说 / ChatGPT 说”可访问性标记；如果未来界面结构变化，可能需要更新适配。
- 正在生成回复时，Codex 的自动跟随可能与历史消息定位短暂竞争；工具会自动重试一次。
- 如果 Codex 为节省资源而没有把很早的历史消息挂载到当前界面，那一部分暂时不会出现在 0.1.0 目录中；已经挂载的消息可以正常读取和定位。
