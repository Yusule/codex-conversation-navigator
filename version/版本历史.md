# 版本历史

版本记录按时间倒序排列。每个版本都包含版本号、改动说明和对应截图。

## 版本规则

- 修复问题：升级第三位版本号，例如 `v1.0.0 → v1.0.1`。
- 增加兼容的新功能：升级第二位版本号，例如 `v1.0.1 → v1.1.0`。
- 出现明显不兼容的变化：升级第一位版本号，例如 `v1.1.0 → v2.0.0`。
- 截图统一存放在 `version/assets/版本历史/`，文件名以对应版本号开头。

## v1.0.3

- 类型：性能修复

### 本次改动

- 点击悬浮球后先立即显示目录窗口，再在后台读取当前 Codex 对话。
- 毛玻璃背景改为提前缓存，展开时不再同步截图和强制计算整窗布局。
- 目录窗口会在悬浮球出现前完成一次透明预热，减少第一次展开的冷启动卡顿。
- 连续展开或刷新时最多执行一个对话扫描任务，期间的重复请求会自动合并为最后一次。
- 入场效果改为 `90ms` 的轻微位移，不再从完全透明逐渐显示。

### 实测结果

- 旧版第一次展开约 `670ms`，新版约 `61–124ms`。
- 旧版加载期间立即收起常需 `421–478ms`，新版通常为 `10–26ms`。

## v1.0.2

- 类型：交互优化

### 本次改动

- 刷新按钮按下时会轻微缩小并切换为更醒目的橙色，松开后平滑恢复。
- 点击后依次显示“刷新中”和“完成”，让刷新结果清晰可见。
- 刷新失败时显示“重试”，可以直接再次点击。
- 反馈文字会自动恢复为“刷新”，按钮宽度保持不变，不会挤动标题栏。
- 系统关闭界面动画时仍保留颜色和文字反馈。

刷新成功后，按钮会短暂显示醒目的“完成”状态：

## v1.0.1

- 类型：修复
- 对应提交：`f328a96`

### 本次改动

- 将目录窗口顶部的标题、对话数量和空白区域统一设为可拖动区域。
- 删除容易被误解为“专用拖动按钮”的双线把手。
- “全部 / 模型 / 用户”“刷新”和“关闭”按钮保持独立点击，不会触发窗口拖动。
- 拖动时目录窗口与悬浮球继续整体移动，并保持固定间距。
- 保留方向键移动和 `Shift + 方向键`精细移动。

## v1.0.0

- 类型：首个可用版本
- 对应提交：`c8f7888`

### 主要功能

- 提供 Windows 本地悬浮球，一键展开当前 Codex 对话目录。
- 使用左右聊天气泡区分用户消息与模型回复。
- 支持“全部 / 模型 / 用户”三种显示模式。
- 点击任意目录项可快速定位到原消息。
- 支持悬浮球与目录窗口整体移动、键盘微调和自动选择展开方向。
- 全程离线运行，不修改 Codex 安装目录，也不向 Codex 进程注入代码。
